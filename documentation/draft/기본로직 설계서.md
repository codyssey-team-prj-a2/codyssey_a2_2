## 품질지표 로직

### ① 데이터 정제 통과율 (Data Cleanliness Rate)

- **의미:** 수집한 날것의 데이터(raw) 중 찌꺼기를 걸러내고 얼마나 유효한 데이터(clean)를 건졌는가?
- **계산 로직:** `(clean 저장소에 저장된 뉴스 수 / raw 저장소에 있는 전체 뉴스 수) * 100`
- **개발 힌트:** SQLite나 JSONL에서 `SELECT count(*)`를 두 번 호출하여 나누기만 하면 됩니다.

### ② AI 요약 성공률 (AI API Success Rate)

- **의미:** 외부 AI API 통신 시 타임아웃이나 에러로 뻗지 않고 얼마나 안정적으로 요약을 완료했는가?
- **계산 로직:** `(요약이 성공하여 저장된 뉴스 수 / summarize 커맨드로 요약을 시도한 전체 뉴스 수) * 100`
- **개발 힌트:** `summarize` 시도 시 전체 대상 건수(`total_target`)를 세고, 성공적으로 리턴받은 건수(`success_count`)를 나누어 백분율로 표기합니다.

### ③ 중복 수집 방지율 (Duplicate Prevention Rate)

- **의미:** 중복 정책(skip/upsert)이 제대로 작동하여 불필요한 데이터를 얼마나 잘 걸러냈는가?
- **계산 로직:** `(중복으로 판정되어 Skip된 건수 / fetch로 수집 시도한 총 건수) * 100`

## TOP N 로직

### ① 최다 출현 핵심 키워드 TOP 5

- **의미:** 현재 수집된 뉴스들에서 가장 많이 언급된 트렌드 키워드는 무엇인가?
- **계산 로직:** `analyze` 단계에서 AI가 뽑아준 핵심 키워드들을 리스트로 모은 뒤, 파이썬의 `collections.Counter` 모듈을 사용해 가장 많이 나온 단어 5개를 내림차순 정렬하여 추출합니다.

### ② 카테고리별 뉴스 수집량 TOP 3

- **의미:** 최근 어떤 분야(정치/경제/IT 등)의 뉴스가 가장 많이 쏟아지고 있는가?
- **계산 로직:** `clean` 저장소에 있는 데이터들을 카테고리 기준으로 그룹핑(Group By)하고 갯수를 카운트하여 상위 3개를 뽑습니다. 딕셔너리(`dict`)를 정렬하는 기초적인 로직으로 쉽게 구현 가능합니다.
