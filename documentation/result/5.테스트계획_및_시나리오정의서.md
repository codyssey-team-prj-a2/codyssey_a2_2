- **프로젝트명**: Python CLI 기반 AI 뉴스 데이터 파이프라인 & 인사이트 리포트 자동화 서비스[cite: 1]

## 1. 개요 (Overview)

### 1.1 목적

본 문서는 소프트웨어 개발 생애주기 동안 수행되는 **단위 테스트(Unit Test)** 및 **통합 라이브 테스트(Integration Test)**의 전략, 환경, 검증 시나리오 및 예외 처리 케이스를 정의하여 시스템의 안정성과 품질을 보장하는 것을 목적으로 한다[cite: 1].

### 1.2 테스트 전략 및 방침

1. **2단계 브랜치 기반 테스트 전략**:
   - **Staging 브랜치 (단위 테스트)**: 모듈별 기초 결함, 예외 처리, 비정상 인자 입력 시 폴백 로직을 검증한다[cite: 1].
   - **Main 브랜치 (통합 테스트)**: 뉴스 수집부터 파일 내보내기까지의 전체 데이터 파이프라인 관통 E2E(End-to-End) 시나리오를 검증한다[cite: 1].
2. **QA 주도 품질 관리**:
   - QA 담당자가 단위/통합 테스트 시나리오를 주도하고 `QA_체크리스트_환경설정테스트.xlsx` 시트 작성 및 피드백을 진행한다[cite: 1].
3. **실제 데이터 및 AI API 검증**:
   - mock 데이터에 의존하지 않고 실제 외부 뉴스 소스(RSS/크롤링)와 실제 AI API 통신 환경에서 에러 방어 로직을 검증한다[cite: 1].

## 4. E2E 통합 파이프라인 검증 결과 (Integration Test Summary)

실제 외부 뉴스 데이터와 실제 AI API 게이트웨이를 사용하여 수행한 관통 테스트 수행 결과 요약이다 (`documentation/result/실행결과_보고서.md` 기반)[cite: 1].

```text
[Step 1] 수집 (fetch)    : 총 49건 수집 완료 (RSS 40건, 크롤링 9건 성공)
[Step 2] 정제 (clean)    : Raw 49건 ──► Clean DB 47건 적재 (중복 URL 2건 자동 병합)
[Step 3] 요약 (summarize): 미요약 10건 3줄 요약 완료 및 DB 반영
[Step 4] 분석 (analyze)  : IT 카테고리 20건 분석 ──► 트렌드/키워드/시사점 DB 저장 완료
[Step 5] 감성 (sentiment): 10건 분석 ──► 긍정 8건, 중립 1건, 부정 1건 DB 저장 완료
[Step 6] 리포트 (report) : 정제 통과율 95.92%, 차트 PNG 3종 생성 및 콘솔 출력 완료
[Step 7] 내보내기(export): CSV, Excel, JSONL 3종 파일 47건 내보내기 정상 완료
```
