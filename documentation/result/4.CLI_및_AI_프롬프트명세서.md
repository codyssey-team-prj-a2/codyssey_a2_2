# CLI 및 AI 프롬프트 명세서 (CLI & AI Interface Specification)

- **프로젝트명**: Python CLI 기반 AI 뉴스 데이터 파이프라인 & 인사이트 리포트 자동화 서비스[cite: 1]
- **대상 레포지토리**: `codyssey-team-prj-a2/codyssey_a2_2` (`main` 브랜치)[cite: 1]
- **문서 버전**: v1.0.2
- **작성일**: 2026-08-14

---

## 1. 개요 (Overview)

본 문서는 `src/main.py` 라우터와 각 서브 모듈(`src/lib/dev/*.py`)에서 구동되는 **CLI 명령어/옵션 스펙**과 **AI API 연동 규격 및 프롬프트 엔지니어링 명세**를 정밀하게 정의한다[cite: 1].

## 3. CLI 예외 처리 및 입력 검증 규칙 (Validation Rules)

1. **숫자 파라미터 경계값 검증 (`--limit`, `--page`, `--size`)**[cite: 1]:
   - CLI 실행 시 `--limit -5` 또는 `--limit 0`, `--limit abc` 등 잘못된 인자가 들어올 경우, 프로세스를 중단시키지 않고 경고 메시지 출력 후 **안전한 기본값(fetch: 20, summarize/sentiment: 10, list: page 1/size 10)으로 자동 폴백(Fallback)** 처리한다[cite: 1].
2. **날짜 포맷 정규화 검증 (`--date-from`, `--date-to`)**[cite: 1]:
   - `_is_valid_date()` 함수를 통해 `YYYY-MM-DD` 규격 검사를 수행한다[cite: 1].
   - 잘못된 날짜 문자열(예: `20260101`, `badvalue`) 입력 시, **"날짜는 YYYY-MM-DD 형식으로 입력해 주세요"** 안내 문구를 출력하고 무효 처리를 수행한다[cite: 1].
3. **Dual Interface 처리 기법**[cite: 1]:
   - `src/main.py` 실행 시 인자 없이 접속하면 TUI 대화형 콘솔 메뉴로 진입하며, 서브메뉴 내에서 직접 CLI 커맨드(예: `fetch --source all`)를 입력하여 즉시 호출할 수 있다[cite: 1].

## 4. AI API 연동 및 프롬프트 엔지니어링 명세 (AI Specification)

### 4.1 Multi-LLM 연동 아키텍처 (`src/lib/common/ai_client.py`)

- **플랫폼 지원**: Gemini (`google-genai`), OpenAI (`requests` 직접 통신), Anthropic (`anthropic`) 분기 지원[cite: 1].
- **재시도 백오프 (Exponential Backoff)**: HTTP 429(Rate Limit) 및 5xx 서버 에러 발생 시 최대 5회 지수 백오프 재시도 수행[cite: 1].
- **OpenAI 게이트웨이 WAF 방어**: OpenAI SDK 대신 `requests` 라이브러리를 사용하여 HTTP 헤더 차단을 회피하고 custom `OPENAI_BASE_URL` 통신 지원[cite: 1].

### 4.2 Gemini Thinking Budget 컨트롤 전략

- Gemini 모델(예: `gemini-2.5-flash`) 연동 시 내부 추론(Reasoning/Thinking)에 출력 토큰 예산을 소모하여 요약/추출 결과가 중간에 잘리는 버그 방지를 위해 `thinking_config = types.ThinkingConfig(thinking_budget=0)`을 적용하여 응답 품질을 유지한다[cite: 1].

---

### 4.3 AI 프롬프트 명세 1: 3줄 요약 (`summarize.py`)

- **목적**: 기사 본문 텍스트를 핵심 3문장 이내의 완성된 문장으로 요약[cite: 1].
- **System Prompt**:

```text
당신은 전문 뉴스 요약 에디터입니다. 아래 제공되는 뉴스 기사의 본문을 읽고, 핵심 내용을 명확한 3문장의 한국어로 요약하세요.
- 불필요한 서론이나 수식어는 제외하고 핵심 사실 위주로 작성하세요.
- 각 문장은 완성된 문장으로 끝내야 합니다.
```

- **User Prompt**:

```text
[제목]: {title}
[본문]: {content}
```

---

### 4.4 AI 프롬프트 명세 2: 종합 인사이트 분석 (`analyze.py`)

- **목적**: 수집된 뉴스 집합에서 트렌드, 키워드, 시사점을 구조화된 JSON으로 추출[cite: 1].
- **System Prompt**[cite: 1]:

```text
당신은 데이터 분석가입니다. 아래는 특정 기간/카테고리에 수집된 뉴스 제목과 요약 목록입니다.
이를 종합해서 다음 JSON 형식으로만 답하세요. 다른 텍스트는 절대 포함하지 마세요.
{"trends": ["...", "..."], "keywords": ["...", "..."], "implications": "..."}
```

- **User Prompt**[cite: 1]:

```text
1. (IT) 한국시니어연구소 "스마일 시니어는 요양 플랫폼" - 요양/플랫폼 연계 강화...
2. (IT) 삼성·LGD 새 성장축은 IT OLED 적용 기대 - 맥북 OLED 적용 논의...
...
```

- **응답 JSON 규격 예시**[cite: 1]:

```json
{
	"trends": ["요양·헬스케어 등 사회서비스에 IT 플랫폼 결합 확산", "제조/IT 솔루션 지식재산(IP) 경쟁 심화"],
	"keywords": ["요양 플랫폼", "AI 기술 진보", "제조IT", "특허 출원"],
	"implications": "제조 및 서비스 전반에서 AI와 지식재산(IP) 중심의 AX 대전환 투자가 확대될 전망임."
}
```

### 4.5 AI 프롬프트 명세 3: 감성 분석 (`sentiment.py`) [보너스]

- **목적**: 뉴스의 어조와 내용을 판단하여 [긍정/부정/중립] 3단 분류 및 원인 제시[cite: 1].
- **System Prompt**[cite: 1]:

```text
당신은 뉴스 감성 분석기입니다. 아래 뉴스 제목과 요약(또는 본문 일부)을 보고 감성을 "긍정", "부정", "중립" 중 하나로 분류하고 이유를 한 문장으로 쓰세요.
다음 JSON 형식으로만 답하세요. 다른 텍스트는 포함하지 마세요.
{"sentiment": "긍정|부정|중립", "reason": "..."}
```

- **User Prompt**[cite: 1]:

```text
제목: {title}
요약: {summary_or_content}
```

- **응답 JSON 규격 예시**[cite: 1]:

```json
{
	"sentiment": "긍정",
	"reason": "신규 요양 플랫폼 출시로 인한 시장 확대 및 서비스 개선 기대감이 반영됨"
}
```
