# 🚀 Codyssey 뉴스 파이프라인 평가자 테스트 가이드 (Test Guide)

본 문서는 평가를 수행하는 전문가 분들이 과제 검증 및 기능 테스트를 원활하게 수행할 수 있도록 작성된 단계별 수행 가이드입니다.

---

## 0. 평가 범위 및 안내 사항

- **평가 방식**: 각 기능별 메뉴 진입 후 대화형 메뉴 또는 **CLI 명령어 직접 입력**을 통해 정상 동작 여부를 확인합니다.
  - 이 프로그램은 편의 제공 및 새로운 아이디어 적용을 위해 대화형 기능을 병행 개발했습니다
- **예외 사항 (환경 설정)**: 요구사항 정의에 따라 **환경 설정 메뉴(메인 1번)는 예외적으로 대화형 메뉴(TUI)**로 구성되어 있으므로, 최초 진입 시 화면 안내에 따라 수동 설정을 진행해 주셔야 합니다.
- **편의성 사전 조치**: 평가 시 RSS 링크를 직접 찾아 입력해야 하는 불편함을 해소하기 위해, **주요 뉴스 피드 URI 3개가 `config.json`에 미리 등록**되어 있습니다. 별도의 소스 검색 없이 바로 수집 테스트를 진행하실 수 있습니다.

## 1. 사전 준비 단계 (Prerequisites)

### 1.1 실행 전 필수 확인 사항

- 테스트 PC에 **Docker Desktop(또는 Docker 엔진)이 실행 중**이어야 합니다. (도커 환경에서 구동되므로 로컬 OS(Windows/Mac) 환경과 무관하게 동일하게 동작합니다.)
- AI 요약 및 분석 기능을 테스트하려면 OpenAI 등 유효한 AI API 키가 필요합니다. 클론 후 프로그램 진입 직후 **[메인 메뉴 1번] 환경 설정**에서 API 키를 등록해 주세요. (뉴스 소스는 이미 3개가 세팅되어 있습니다.)

### 1.2 저장소 클론 및 Docker 실행

1. 프로젝트 레포지토리를 클론(Clone) 받습니다.
2. 터미널을 열고 `docker` 디렉토리로 이동한 뒤, 실행 권한을 부여하고 빌드 및 컨테이너를 실행합니다.
   ```bash
   cd docker
   chmod +x run.sh
   ./run.sh
   ```

### 1.3 프로그램 진입

- 컨테이너 내부 터미널(또는 프로젝트 루트)에서 아래 명령어를 입력해 메인 진입 화면으로 이동합니다.
  ```bash
  python3 main.py
  ```

### 1.4 정기 수집(Cron) 백그라운드 동작 확인 (참고)

- 본 프로젝트는 Docker 컨테이너 내부에 Linux `cron` 데몬이 내장되어 있어, 백그라운드에서 **10분 주기로 자동 수집(`automation.py`)**이 동작하도록 설계되어 있습니다.
- 로그 위치는 ../src/logs/ 입니다. 프로그램 로그와 별도로 관리됩니다.
- 수집된 로그는 아래 명령어로 실시간 확인할 수 있습니다.
  ```bash
  ../logs/cron_fetch.log 아래 과정 종료후 파일 확인해주세요. (10분 후 동작)
  ```

## 2. 기능별 실행 및 테스트 단계 (Execution & CLI Test)

메인 화면의 메뉴 순서에 따라 각 서브메뉴에 진입하여 대화형 기능과 **CLI 직접 입력 명령어**를 차례대로 테스트합니다. 각 서브메뉴 안에서 `h`를 누르면 상세 도움말과 옵션을 확인할 수 있습니다.

### [설정] 환경 설정 (Setup) ※ 최초 1회 필수

- **진입**: 메인 메뉴에서 `0` 입력
- **설명**: AI API 키 입력 및 미리 등록된 뉴스 수집 소스(3개)를 확인/설정하는 대화형 설정 화면입니다.

### [메뉴 1] 뉴스 데이터 수집 (Fetch)

- **진입**: 메인 메뉴에서 `1` 입력
- **CLI 테스트 명령어**:
  ```bash
  fetch --source all --limit 10
  ```

### [메뉴 2] 데이터 정제 (Clean)

- **진입**: 메인 메뉴에서 `2` 입력
- **CLI 테스트 명령어**:
  ```bash
  clean --policy skip
  ```

### [메뉴 3] AI 기사 요약 (Summarize)

- **진입**: 메인 메뉴에서 `3` 입력
- **CLI 테스트 명령어**:
  ```bash
  summarize --unsummarized --limit 5
  ```

### [메뉴 4] AI 감성 분석 (Sentiment)

- **진입**: 메인 메뉴에서 `4` 입력
- **CLI 테스트 명령어**:
  ```bash
  sentiment --unanalyzed --limit 5
  ```

### [메뉴 5] 정제 뉴스 목록 조회 (List)

- **진입**: 메인 메뉴에서 `5` 입력
- **CLI 테스트 명령어**:
  ```bash
  list --page 1 --size 10 --category IT
  ```

### [메뉴 5-1] 정제 뉴스 목록 상세 조회 (Show)

- **진입**: 뉴스 목록조회 - 게시판 형태 리스트 출력된 페이지에서 수행
- **CLI 테스트 명령어**:
  ```bash
  show --no [No]
  ```

### [메뉴 6] AI 종합 인사이트 분석 (Analyze)

- **진입**: 메인 메뉴에서 `6` 입력
- **CLI 테스트 명령어**:
  ```bash
  analyze --date-from 2026-08-01 --date-to 2026-08-07 --category IT
  ```

### [메뉴 7] 인사이트 리포트 및 차트 (Report)

- **진입**: 메인 메뉴에서 `7` 입력
- **CLI 테스트 명령어**:
  ```bash
  report --format md --date-from 2026-08-01 --date-to 2026-08-07
  ```

### [메뉴 8] 데이터 내보내기 (Export)

- **진입**: 메인 메뉴에서 `8` 입력
- **CLI 테스트 명령어**:
  ```bash
  export --format csv --status summarized
  ```

### [종료] 프로그램 종료하기

- **종료**: 메인 메뉴에서 `q` 입력
