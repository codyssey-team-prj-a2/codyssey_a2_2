# 화면 예시 (UI Screenshots)

- **문서 목적**: 대화형 콘솔(TUI) 및 CLI 직접 입력 모드의 실제 실행 화면을 캡처하여, 개편된 UI 흐름을 페이지 단위 샘플로 공유한다.
- **관련 문서**: [4. CLI 및 AI 프롬프트 명세서](./result/4.CLI_및_AI_프롬프트명세서.md)

## 1. 메인 화면 (환경 설정 완료 상태)

<img src="../images/ui0.jpg" width="100%"/>

- 상단 상태 바가 `환경 설정 (4/4 완료 - AI:O | 뉴스:O | DB:O | 로그:O)` 형태로 표시되어, 세부 설정 항목별 완료 여부를 한눈에 확인할 수 있다.
- 메뉴 진입 번호를 `2~7`(핵심 파이프라인)과 `8~10`(보너스 기능)으로 구분해, 화면 진입 시 혼란을 주던 숫자 배치를 정리했다.

## 2. 뉴스 수집(fetch) CLI 직접 입력 실행 화면

<img src="../images/ui1.jpg" width="100%"/>

- `fetch --source all --limit 5` 명령을 직접 입력하면 소스별 수집 진행 상황과 결과(추출 건수, raw 저장 완료 여부)가 실시간으로 출력된다.
- 아직 지원하지 않는 수집 방식(`api`)에 대해서는 에러 없이 `[건너뜀]` 안내 후 나머지 소스 수집을 계속 진행한다.

## 3. 데이터 정제(clean) 제어소 및 미리보기 화면

<img src="../images/ui2.jpg" width="100%"/>

- 번호 선택형 메뉴와 CLI 직접 입력(`clean --policy [skip|upsert]`)을 한 화면에서 함께 안내한다.
- `정제 미리보기` 실행 시 raw 전체 건수, 필수 필드 누락 제외 건수, 정제 통과 건수와 상위 샘플 기사 목록을 확인할 수 있다.
