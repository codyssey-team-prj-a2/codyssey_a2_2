- **테스트 방식**: 요구사항 정의서(FR/NFR) 및 QA 체크리스트 항목을 실제 소스 코드와 대조하는 코드 기반 검증 + 대화형/CLI 실행 화면 캡처를 통한 동작 확인
- **재검증일**: 2026-08-15

## 1. 요약

이번 UI 개편(대화형 메뉴 번호 체계 정리, `list`/`show` 조회 UI 개선) 및 기능 보완 이후 재검증한 결과, 핵심 체크리스트 14개 항목 중 **8개 완료 / 3개 부분완료 / 3개 미완료**로 확인되었다. 이전 라운드 대비 데이터 정제(`clean`) 로직, SQLite 저장 경로 버그, `list`/`show` 보너스 조회 기능이 완료 상태로 전환되었다.

| 상태 | 항목 수 | 항목 |
|---|---|---|
| ✅ 완료 | 8 | 옵션 지원(`--limit/--category/--date/--format`), HTTP 타임아웃/오류처리, raw 저장 메타데이터, 데이터 정제 로직, SQLite/JSONL 영구저장, 모듈 분리, 웹UI 미사용(TUI 전용), `list`/`show` 조회 |
| 🟡 부분완료 | 3 | API/크롤링 두 방식(Selenium 미구현), 중복 skip/upsert 정책(로직 완료·영구 설정 UI 부재), config.json 설정 관리(중복정책 UI 부재) |
| ❌ 미완료 | 3 | `main.py` 진입 시 argv 기반 서브커맨드 즉시 실행(FR-00-02), `logging` 모듈 기반 로그 기록, 크롤링 요청 간 지연(delay) |

> 남은 미완료/부분완료 6개 항목은 이번 재검증에서도 코드상 그대로 확인되어, 실제로 고쳐지지 않은 항목까지 "완료"로 표기하지는 않았다. 필요 시 위 3개 미완료 항목(특히 `logging` 연동, 크롤링 delay)은 비교적 작은 패치로 해결 가능하니 요청 주시면 이어서 작업 가능하다.

## 2. 실행 화면 캡처 기반 동작 확인

### 2.1 메인 화면 진입 (환경설정 4/4 완료 상태)

<img src="../../images/ui0.jpg" width="100%"/>

메뉴 진입 번호가 `2~7`(핵심 파이프라인) / `8~10`(보너스)으로 정리되어, 기존에 혼란을 주던 번호 배치 문제가 해소됨을 확인했다.

### 2.2 뉴스 수집(`fetch`) CLI 직접 입력 동작 확인

<img src="../../images/ui1.jpg" width="100%"/>

`fetch --source all --limit 5` 실행 시 RSS/크롤링 소스별 수집 결과가 정상 출력되고, 미구현 방식(`api`)은 예외 없이 안내 후 건너뛰는 것을 확인했다.

### 2.3 데이터 정제(`clean`) 메뉴 및 미리보기 동작 확인

<img src="../../images/ui2.jpg" width="100%"/>

정제 미리보기 실행 시 raw 전체 건수, 필수 필드 누락 제외 건수, 정제 통과 건수가 정확히 집계되어 출력됨을 확인했다(예시: raw 285건 중 1건 제외, 284건 통과).

## 3. 남은 이슈 (이슈체크리스트_요약 시트 참고)

핵심 체크리스트 외에 별도로 추적 중인 UX/개선 이슈(예: 화면별 취소 키 `C`/`P` 불일치, DB·로그 경로 형식 검증 부재, AI 모델명 자유 입력 검증 부재 등)는 이번 재검증 범위에서 전수 재확인하지는 않았으며, `QA_체크리스트_환경설정테스트.xlsx`의 **이슈체크리스트_요약** 시트에 기존 상태 그대로 남아있다. 필요 시 별도 라운드로 재검증 가능하다.
